# Field Treatment Review
 
An AI-assisted review system for agricultural field-treatment requests.
 
A field agronomist requests a chemical treatment for a field. The system checks the request against product labels, farm records, and the weather forecast, then recommends it for human approval, sends it back for revision, asks for missing information, or escalates it. A person makes the final call.
 
MVP Scope: soybeans, Missouri, 5 products, ~10 synthetic fields.
